# Drive Rule - Matthew Effect

`drive = :matthew` — the opposite of [[Drive Rule - Avoid Crowded]]: joins
the *most* crowded of the sampled theories.

Hot topics attract more people — Merton's Matthew effect (see
[[References]]) built directly into the entry rule, rather than emerging
from it.

## Numbers (L=24)
- stationary density: 2.009
- activity: 0.918 — almost every step triggers *something*
- mean avalanche size ⟨s⟩: 33.7 — the smallest of the four fixed rules
- τ (truncated power-law fit): 0.713

Piling onto whatever is already hot keeps burning the pile down locally, so
it rarely accumulates enough stress for a large cascade: busier science,
smaller consequences. See [[Research Questions]] for the welfare framing
this suggests.

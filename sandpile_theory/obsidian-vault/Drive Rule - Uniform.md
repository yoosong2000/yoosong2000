# Drive Rule - Uniform

`drive = :uniform` — a new scientist starts on a theory picked completely at
random, no comparison at all.

This **is** plain [[Bak-Tang-Wiesenfeld Sandpile|BTW]] driving, dressed up
with the credit bookkeeping from [[Theory-Scientist Mapping]]. It's the
control every other rule in [[Research Questions]] is judged against — if a
modified rule doesn't reproduce this one's numbers when the modification is
turned off, something in the extra machinery broke the sandpile instead of
extending it.

## Numbers (L=24)
- stationary density: 2.085 (BTW reference ≈ 2.125)
- activity: 0.421 of steps trigger a cascade
- mean avalanche size ⟨s⟩: 56.3
- τ (truncated power-law fit): 0.874 — see [[Truncated Power-Law Fitting]]

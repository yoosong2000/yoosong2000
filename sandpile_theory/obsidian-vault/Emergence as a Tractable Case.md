# Emergence as a Tractable Case

Philosophers arguing about emergence usually have either toy cellular
automata with no interpretive content, or richly interpreted social
phenomena with no formal handle. [[Self-Organized Criticality]] is unusual
in offering both at once.

## What's emergent here

A macro-regularity — the critical exponent τ, universality-class membership
— that is:
- **fully bottom-up**: nothing is added at the aggregate level that isn't
  already in the agent rules (see [[Theory-Scientist Mapping]])
- **substrate-independent across different microscopic rules**:
  [[Drive Rule - Uniform]], [[Drive Rule - Frontier]], and
  [[Drive Rule - Novelty-Seeking|novelty_weight ≥ 0.5]] all land in a
  similar τ ≈ 0.5–0.9 band despite genuinely different mechanisms generating
  that band
- **yet not predictable by just inspecting one agent's rule** — you have to
  run the aggregation to find out which universality class a given rule
  lands in; see the sharp step in [[Novelty-Seeking Phase Transition]]

> [!tip] Why this is useful outside physics
> This is a clean, checkable instance of "weak emergence" — macro-pattern
> fixed by micro-rules with no further ingredients, but not trivially
> readable off them — to reason from, instead of the usual hand-wave about
> social phenomena being "more than the sum of their parts."

See [[Aggregation Failure]] for the companion question about whether that
sum is also a *good* one.

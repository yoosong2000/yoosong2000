## Page structure / build notes (for implementing elsewhere)

- **Format:** single static HTML file (Claude Artifact), no backend, no live data — a dated snapshot.
- **Sections, top to bottom:** sticky header (title, subtitle, search box, "gaps to verify" callout) → jump-nav chip row → Group 1 cards → Group 2 cards → Group 3 cards → Thematic Watch cards → footer methodology note.
- **Per-journal card:** journal name, publisher + issue/volume badge (or "Online First" badge for continuous-publication journals), external link to the live TOC, article list (title + author, DOI-linked where available), optional caveat note.
- **Search:** vanilla JS filters cards by a `data-search` attribute (lowercased journal name + article titles + authors); hides empty groups.
- **Flagged/gap items:** styled with a dashed border and amber "warn" badge (`Journal of Philosophy`, `BJPS`, `Philosophy of Data`), plus a summary callout box under the header linking to each.
- **Design tokens:** Newsreader (serif, headings/journal names) + Work Sans (body) + IBM Plex Mono (metadata/badges/labels); warm stone-grey background, deep pine-teal accent; full light/dark theme support via CSS custom properties.
